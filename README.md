# DiskLens · 磁盘透镜

简体中文 | [English](README.en.md)

看清目录占用，找到大文件。DiskLens 是本地运行的 macOS 磁盘分析工具，提供目录列表、最大文件与占用地图，并通过文件事件持续更新索引。

原生 SwiftUI / AppKit 界面 · SQLite 本地索引 · 无第三方运行依赖 · 无账号、上传或遥测 · [MIT](LICENSE)

![DiskLens 占用地图](docs/preview.png)

> 截图由当前代码的真实界面渲染，目录、文件与容量均为合成演示数据。

## 主要功能

- **三种占用视图**：浏览目录汇总、查找最大文件，或用 Treemap 方块面积比较占比。地图支持悬停详情、双击下钻和键盘选择。
- **完整索引与增量更新**：首次扫描建立缓存，后续通过 FSEvents 更新变化。支持暂停、继续和中断恢复，可浏览已提交的部分结果。
- **搜索与导航**：名称或完整路径搜索、子目录检索、分页，以及目录历史和祖先路径跳转。后台刷新保留当前列表与交互。
- **文件操作**：Finder 定位、复制路径、为文件选择打开方式。移到废纸篓前确认并校验文件身份。
- **菜单栏与设置**：磁盘剩余空间、容量提醒、登录启动、缓存预算和回收。关闭窗口后仍可从菜单栏打开。

## 构建与启动

需要 **macOS 13 或更新版本**，并安装 Apple Command Line Tools：

```sh
xcode-select --install
```

克隆仓库并构建：

```sh
git clone https://github.com/lxfu1/disk-lens.git
cd disk-lens
bash scripts/build.sh
open dist/DiskLens.app
```

构建输出为 `dist/DiskLens.app`，仅包含当前机器架构，使用本机 ad-hoc 签名。当前提供源码构建方式，尚未提供 Developer ID 签名、公证或应用内自动更新。

可将应用放入“应用程序”目录并保持位置固定。首次普通启动不会自动扫描整个用户目录；选择一个目录或点击“开始分析”即可建立索引。

要在新启动的进程中分析指定目录，先退出已运行的 DiskLens，再执行：

```sh
open dist/DiskLens.app --args --scan /path/to/folder
```

重新构建后需退出旧进程再打开。关闭窗口不会退出应用，可用菜单栏的“退出 DiskLens”或 `⌘Q`，也可在应用运行时执行：

```sh
osascript -e 'tell application id "local.disklens.app" to quit'
open dist/DiskLens.app
```

## 使用说明

### 浏览、搜索与复制

“目录占用”展示直接子项，“最大文件”展示当前目录及子目录中的普通文件，每页最多 200 项。搜索支持名称与完整路径，“含子目录”控制目录视图的搜索范围。

左侧导航整行可点击；重复点击当前目录会保留搜索、选择和结果。路径菜单可以跳转祖先目录，也支持前进和后退。顶部复制按钮成功后原位显示勾号，并在按钮上方提示“已复制路径”约 2 秒；选中项目后，底部“复制路径”复制该项目的完整路径。

后台更新保留已有结果和浏览操作，只在状态图标上显示动画。搜索或翻页期间限制旧结果操作；查询失败可重试，分页游标因索引变化失效时会返回第一页并提示。

![目录列表与搜索](docs/screenshots/directory.png)

### 占用地图

方块面积表示已分配空间占比，悬停查看大小、占比和路径。选中或悬停通过透明度变化反馈；文件右键菜单提供打开方式、Finder 定位和复制路径。

地图展示最大的 200 项，其余合并为“其他占用”；双击该区域切回无搜索过滤的列表。零占用项目请在列表查看。索引未完成时数据为暂计，汇总或硬链接校准期间可能变化。

### 暂停、继续与重建

扫描或更新时可以暂停。暂停后切换目录、前进/后退和搜索只读取缓存；无缓存目录等待手动分析，不会因导航自动恢复扫描。点击“继续分析”（`⌘R`）恢复当前目录，暂停状态在本次运行期间保留。

“刷新”请求交付已缓冲的文件事件；“重建索引…”重新扫描所属索引范围，执行前会确认实际范围，可能比当前子目录更大。读取权限发生变化后可重建校准。

### 设置与缓存

从侧栏、应用菜单或 `⌘,` 打开设置：

- **登录启动**：首次默认申请开启，之后尊重关闭选择；若系统要求批准，设置页提供登录项入口。
- **容量提醒**：默认关闭，开启时申请通知权限；每分钟检查所选目录所在磁盘。
- **缓存预算**：默认估算预算 2 GiB，优先清理旧的完整范围，保护当前范围和未完成任务，因此并非磁盘占用硬上限。

侧栏“索引缓存…”可查看数据库、写入日志、可回收空间和迁移备份，清理缓存不会删除用户文件。

## 数据与统计边界

索引只保存文件元数据，位于 `~/Library/Application Support/DiskLens/`；偏好域为 `local.disklens.app`。应用不读取文件内容用于分析，也不上传索引。

占用基于已分配块数，硬链接在一个索引范围内仅计一次；不跟随目录符号链接，不跨文件系统。APFS 共享块、快照与系统数据可能造成统计差异，**扫描合计不等于可释放空间**。无法读取或跨盘的位置会提示缺口，桌面、文稿、下载等目录可能需要 macOS 隐私授权。

移到废纸篓不会立即释放空间，DiskLens 不会自动清空废纸篓。受保护的系统路径、范围外路径及身份已变化的文件会被拒绝操作。

当前索引格式为 schema v5，0.7–0.9 缓存可直接读取。旧 v2/v3/v4 库需先退出应用，再运行 `python3 -B scripts/migrate-index.py`；迁移保留 `.pre-v5` 备份并需要额外空间。迁移、回退与统计细节见[索引架构](docs/ARCHITECTURE.md)。
