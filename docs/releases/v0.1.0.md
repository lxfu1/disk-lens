# DiskLens v0.1.0 · macOS Preview

首个公开预览安装包 / First public preview package.

## 下载与安装

- `DiskLens-0.1.0-arm64.dmg`：适用于 **macOS 13+、Apple Silicon（M 系列）**；不包含 Intel 版本。
- 打开 DMG，将 DiskLens 拖入 Applications，再从“应用程序”启动。更新前先退出旧进程。
- `SHA256SUMS.txt`：下载完整性校验。在两个文件所在目录执行 `shasum -a 256 -c SHA256SUMS.txt`。

**此预览版仅采用 ad-hoc 签名，没有 Apple Developer ID 签名或公证。macOS 可能阻止首次启动，提示无法验证开发者或无法检查恶意软件。** 只有确认来源为本仓库且信任该应用时，才考虑在尝试启动后通过“系统设置 → 隐私与安全性 → 仍要打开”放行（若系统提供）。不要关闭系统 Gatekeeper；设备管理策略可能禁止放行。

若提示“已损坏”，请先重新下载并核对校验值，不要直接视为误报；如果明确检测到恶意软件，请停止打开。校验值不代表安全审核或公证。尚未提供应用内自动更新。

## 本版功能

- 目录占用、最大文件、Treemap 占用地图，支持搜索、悬停详情和文件右键操作。
- SQLite 完整索引、FSEvents 增量更新、扫描暂停/继续与中断恢复。
- 稳定的后台刷新、侧栏导航和复制路径就近反馈。
- 菜单栏容量信息、登录启动、容量提醒和索引缓存管理。
- 新版磁盘图标，中英文 README 与合成数据截图。

应用界面目前为简体中文。首次普通启动不会扫描整个用户目录，选择目录后开始分析。登录启动默认申请开启，可在设置中关闭；容量通知默认关闭。已有 schema v5 缓存可直接读取，旧 v2/v3/v4 缓存需先退出应用并按 README 迁移。占用基于已分配空间估算，不等于实际可释放空间。

## Installation and security (English)

Download `DiskLens-0.1.0-arm64.dmg` for **macOS 13+ on Apple Silicon**. No Intel build is included. Open the DMG, drag DiskLens to Applications, and launch it there. Quit the old process before updating. Download `SHA256SUMS.txt` alongside the DMG and run `shasum -a 256 -c SHA256SUMS.txt` in that directory.

**This preview is ad-hoc signed, without Developer ID signing or Apple notarization. Gatekeeper may block the first launch with an unidentified-developer or malware-check warning.** Only if you have verified the source and trust the app, consider using **System Settings → Privacy & Security → Open Anyway** after the blocked launch, if available. Do not disable Gatekeeper system-wide. Managed devices may not allow an override.

If macOS reports a damaged file, download it again and check its checksum rather than assuming a false alarm. Do not proceed if macOS explicitly detects malware. Checksums verify integrity, not safety or notarization. In-app automatic updates are not available.

## Highlights

- Directory usage, largest files, and an interactive treemap with search and file context menus.
- Local SQLite indexing, FSEvents updates, pause/resume, and recovery of interrupted scans.
- Background refresh without replacing the page, improved sidebar navigation, and copy confirmation beside the button.
- Menu bar capacity display, launch at login, capacity alerts, and index cache management.
- Updated disk icon, bilingual README, and screenshots using synthetic data.

The current UI is in Simplified Chinese. A normal first launch does not scan the entire home directory. Launch at login is requested by default and can be disabled in settings; notifications are off by default. Existing schema v5 caches remain compatible; older v2/v3/v4 caches require an offline migration as described in the README. Allocated-space totals are not a promise of reclaimable space.

## 验证范围 / Validation scope

主界面与设置的定向检查已通过；安装包构建、架构、签名完整性、DMG完整性及校验值在发布前检查。未完成 Intel / 所有受支持macOS版本、通知授权及登录启动的端到端验证，未运行全套测试或完整CI。

Targeted main-window and settings checks have passed. Packaging checks cover the build, architecture, signature integrity, DMG integrity, and checksums. Intel, every supported macOS version, notification authorization, and login startup have not been validated end to end. The full test suite and full CI were not run.
